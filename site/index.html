Application de bureau · Java

Évaluer des CV avec l’aide de l’IA

Resume Evaluator récupère les CV reçus dans Gmail et les compare à un descriptif de poste. Choisissez un modèle de langage (LLM) pour une évaluation assistée par IA, ou une analyse locale par mots-clés.

Télécharger l’application Voir le projet sur GitHub

L’évaluation est une aide au tri et ne remplace pas l’examen humain des candidatures.

01

Évaluation par LLM

Utilisez OpenRouter, Anthropic, OpenAI, Mistral, Ollama ou une API compatible. Avec un fournisseur externe, le texte du CV et le descriptif de poste sont transmis à ce fournisseur pour l’évaluation.

02

Analyse par mots-clés

Une option sans LLM compare localement les mots-clés du descriptif et des CV. Le contenu des CV n’est alors pas envoyé à un service d’IA.

03

Rapport Excel

Consultez les scores, résumés, points forts et points à vérifier dans un rapport Excel enregistré à l’emplacement que vous choisissez.

Accès Gmail

Lecture seule, avec votre autorisation

L’application demande le droit OAuth gmail.readonly. Le jeton de renouvellement est conservé sur votre ordinateur. Les CV, les données personnelles qu’ils contiennent et les résultats doivent être traités avec précaution.
